How the tool works, in one paragraph

Nuke does not run the AI model itself. When you press OK in the panel, the tool writes a small job file and starts a separate engine program in the background. The engine turns your clip into a linear EXR "plate", runs CorridorKey 2.0 on the graphics card, and writes the alpha (matte), the foreground colour and a despilled foreground as EXR files. Nuke then loads these back for you, already wired into a ready-to-use comp. You can keep working in Nuke while it runs.

2. Before you start (checklist)

Check these on the other PC (the one with the RTX 3050) before installing:

  • Windows 10 or 11, 64-bit.
  • NVIDIA driver version 570 or newer. To check: press Start, type cmd, press Enter, then type nvidia-smi and press Enter. The number after "Driver Version" must be 570 or higher. If it is lower, or the command is not found, install the latest Game Ready or Studio driver from nvidia.com (or the NVIDIA App) and restart the PC.
  • About 30 GB free on the drive you install to: 10 GB for the tool, and at least 20 GB for shots. Keyed EXR files are large.
  • Enough Windows memory. The engine needs about 15 GB of RAM + page file. On a 16 GB PC, keep the page file on a drive with plenty of free space (the setup check tests this; section 14 shows how to move it).
  • Nuke is installed (Non-commercial or commercial). It was tested on Nuke 17.1v2; any Nuke with Python 3 should work.
  • A USB / external drive with at least 11 GB free to carry the folder.
Which drive letter?The installer puts everything on D:\ by default (D:\CorridorKey2, D:\nuke plugin, shots in D:\CKShots). If the other PC has no D: drive, or you prefer another drive, step 4 shows how to choose it.

3. Copy the folder to the USB drive

Do this on this laptop.

  1. Plug in the USB drive. Open File Explorer and note its drive letter (for example E: or F:).
  2. Open D:\ in File Explorer. Right-click the folder CK2_bundle and choose Copy.
  3. Open the USB drive, right-click an empty area and choose Paste. Copying 9.9 GB takes a few minutes to half an hour depending on the drive.
  4. When it finishes, check the copied folder: right-click it on the USB drive, choose Properties, and confirm the size is about 9.9 GB. A smaller size means the copy did not finish.
  5. Eject the USB drive safely (right-click it in File Explorer, Eject).
Any USB format worksThe largest single file in the folder is 2.5 GB (the CorridorKey weights), so drives formatted as FAT32, exFAT or NTFS can all hold it.

4. Install on the other PC

  1. Close Nuke if it is open.
  2. Plug the USB drive into the other PC and note its drive letter. The examples below use E:; replace it with yours.
  3. Press Start, type PowerShell, and open Windows PowerShell (normal, not "as administrator").
  4. Copy this line, paste it into PowerShell (right-click pastes), and press Enter: 
    powershell -ExecutionPolicy Bypass -File "E:\CK2_bundle\install_bundle.ps1"
    This installs to the D: drive. To install to another drive instead, add -Root and -Shots, for example for the C: drive: 
    powershell -ExecutionPolicy Bypass -File "E:\CK2_bundle\install_bundle.ps1" -Root "C:\" -Shots "C:\CKShots"
  5. Wait. It prints "Copying the engine..." and copies about 10 GB from the USB drive, which usually takes 5 to 20 minutes. Do not close the window.
  6. It then prints "Adding the CorridorKey 2.0 menu to Nuke..." and finally a setup checklist (next page). When every line says PASS, the install is done.

6. First start in Nuke

  1. Start Nuke as usual.
  2. In the top menu bar you now see CorridorKey 2.0. Its items are: Key shot..., Prepare plate only..., Load latest key of a shot..., Clean up a shot... and About.
  3. Click CorridorKey 2.0 → About. It shows the tool folder, the engine Python and the shots folder. These should point at the drive you installed to.
Nuke Non-commercial limitsNuke NC cannot read MP4/MOV files and renders at most 1920×1080. The tool works around both: it decodes video itself (section 7), and it scales Roto hints from NC to the plate size. Keys themselves are always made at the full plate resolution, including 4K.

7. Key an MP4 / MOV clip (step by step)

Use this for phone or camera video. Because Nuke NC cannot open MP4/MOV, you first let the tool make a plate.

  1. Click CorridorKey 2.0 → Prepare plate only.... The panel opens with "prepare plate only" ticked.
  2. source is set to "File on disk". Click the folder icon next to file and pick your video.
  3. shot name fills in from the file name; change it if you like. shots folder is where the files go (default D:\CKShots).
  4. Set colour space to what the camera recorded. For normal phone video use "sRGB / Rec.709 video (phone, most cameras)". For log footage choose the camera's log (for example Sony S-Log3). Never key log footage as sRGB.
  5. Leave first/last at 0 / 0 for the whole clip, or type a frame range (video frame 1 is the first frame).
  6. Click OK. A progress bar shows "preparing plate". When it finishes, a Read node with the linear EXR plate appears in the node graph.
  7. (Optional) Draw a Roto around the subject on this plate to help the model pick the right person or object. See section 9.
  8. Select the plate Read (and the Roto, if you made one; hold Shift to select both).
  9. Click CorridorKey 2.0 → Key shot.... Check the settings (the defaults are good for most shots), then click OK.
  10. A progress bar shows the stages: preparing, loading the model, keying windows, writing frames, despill. You can keep working in Nuke. Cancel on the progress bar stops the key.
  11. When it finishes, a Backdrop appears with the plate, alpha, foreground and a finished comp (section 11).
Tip: preview firstTick preview only and set frames to 16 or 24. The tool keys just the first frames into a "preview" folder, so you can check the colour space and settings in about a minute before keying the whole shot.
One step instead of twoIf you do not need a Roto hint, you can skip "Prepare plate only": open Key shot... with nothing selected, pick the video under "File on disk" and click OK. The plate is made and keyed in one go.

8. Key an EXR or DPX sequence

  1. Bring the sequence in with a normal Read node.
  2. Select the Read (and a Roto hint if you have one).
  3. Click CorridorKey 2.0 → Key shot.... The panel shows the Read's file, frame range and size, and picks "Linear Rec.709 (EXR plates)" for EXR files. If your EXRs are ACEScg, choose "ACEScg (linear AP1 EXR)" instead.
  4. Check the shot name and shots folder, then click OK.

9. Using a Roto as a hint

A hint tells the model which subject to key. It helps most when there are several people or objects, or when the model keeps something you do not want.

  1. View the plate and create a Roto node. Draw a shape around the subject on the first frame of the range. White inside the shape means "keep this".
  2. Select the plate Read and the Roto, then open Key shot.... The hint setting switches to "Selected node, first frame (e.g. Roto)" by itself.
  3. Set hint quality to match how careful the shape is: 0.95 for careful roto, 0.75 for a rough box or loose shape, 0.5 for a scribble. A rough shape at 0.95 makes the model trust the shape too much, and screen can be left inside it.
  4. For a subject that moves a lot, animate the Roto and choose "Selected node, every frame".
Hint optionWhen to use it
None (model picks the subject)One clear subject. Try this first.
Selected node, first frame (e.g. Roto)Point at the subject once; the model follows it through the shot.
Selected node, every frameAn animated Roto or matte for every frame.
Matte file, first frameA matte image on disk instead of a node.
Matte file / sequence, every frameA matte image sequence or a matte video on disk.

The invert tick box swaps black and white in the hint (use it if your matte is black on the subject).

11. What you get back

When a key finishes, the tool adds a labelled Backdrop to the node graph containing:

plate(original, linear) fg(despilled colour)+ alpha→Copy→Premult→ Merge (over)←grey BG

Replace the grey background with your own plate to comp. All Reads are set to linear and the full plate resolution.

The shot folder on disk

D:\CKShots\<shot>\
  job.json  status.json  log.txt   settings used, result, full log
  plate_lin\   plate.1001.exr ...  linear plate (reused when you key again)
  hint\                            hint images made from your Roto
  key\v001\    alpha\  fg\  fg_despill\     first key
  key\v002\    ...                          each new key is a new version
  key\preview\                              preview keys (overwritten each time)

Keys are never overwritten: every full key makes a new version folder (v001, v002...). Only preview is replaced.

12. Recommended settings for an RTX 3050 8 GB

The RTX 3050 has the same 8 GB of memory as the laptop the tool was tested on, so the same settings apply. It is a slower card, so keys take longer. Speed on the RTX 3050 has not been measured yet. For reference, on the RTX 5060 Laptop a 16-frame 1080p shot took about 60 to 75 seconds in total (most of it is loading the model, which happens once per key), and 4K took about 95 seconds plus 4.5 seconds per frame.

FootageRecommended settings
HD / 1080p (most shots)Leave the defaults: window auto, low VRAM off, crop auto, despill 1.0 edges + bounce, refine hair/fur.
2K / 1440pDefaults. If you get a memory error, tick low VRAM.
4K / UHDTick low VRAM. Keep crop on auto (it helps a lot when the subject does not fill the frame). Use a preview of 16 frames first. If it still runs out of memory, set window to 8, then 4.
Long shots (hundreds of frames)Fine: the engine works through the shot window by window. Make sure the shots drive has room (4K needs about 25 MB per frame per pass).
Free up GPU memory before a big keyClose web browsers, DaVinci Resolve, games and other GPU apps. In Nuke, set the Viewer to a small frame or proxy while the key runs. The model needs about 4 to 6 GB.

Hair and fur shots

  • Defaults are tuned for hair and fur: despill "edges + bounce" removes green light on white fur, and refine "hair/fur" keeps fine strands.
  • If small patches of screen stay green inside the subject (for example a gap between an animal's legs), draw a Roto hint around the subject with hint quality 0.75, or set despill where to "everywhere" if the subject has no green in it.
  • Fur tips come out as soft gradients rather than single hairs. That is the model's limit, not a setting.

13. The other menu items

Keying without Nuke (optional)

Every key is described by a job.json in the shot folder. To run a job again, or many jobs one after another, from cmd:

"D:\nuke plugin\run_job.bat" "D:\CKShots\myshot\job.json"
"D:\nuke plugin\run_queue.bat" "D:\CKShots"

run_queue.bat keys every job.json it finds under the folder. Load the results with "Load latest key of a shot...".

14. Troubleshooting

Every key writes log.txt and status.json in its shot folder. Open log.txt first; the last lines say what went wrong.

Message or problemWhat to do
No CorridorKey 2.0 menu in NukeRun the "Add the Nuke menu" command from section 5 and restart Nuke. Check C:\Users\<you>\.nuke\init.py contains a line ending in "CorridorKey 2.0 tool".
"The GPU ran out of memory", "ran out of Windows memory", or "engine crashed (access violation)"Usually Windows memory, not the graphics card: the engine needs about 15 GB of RAM + page file. Run the setup check (section 5); if "Windows memory" says FAIL, move the page file to a drive with space (see the row below). Otherwise close other GPU programs (other Nuke windows, cineSync, browsers), tick low VRAM, or set window to 4. The tool already retries by itself with a smaller window.
Setup check: "Windows memory (RAM + page file)" FAILThe page file is too small or on a nearly full drive. Press Start, type Adjust the appearance and performance of Windows, open it, go to Advanced → Virtual memory → Change. Untick "Automatically manage", select the D: drive, choose System managed size, click Set, then OK, and restart the PC.
"CorridorKey venv python not found" or "weights missing"Paths are wrong. Run the setup check (section 5); re-run the installer if files are missing.
"ffmpeg not found"Check the ffmpeg lines in nuke plugin\settings.local.json.
Key looks washed out or too contrastyWrong colour space or range. Check the camera setting; try range "limited" or "full".
Green screen left inside the subjectAdd a Roto hint (quality 0.75 for a rough shape). If you used a rough Roto at 0.95, lower it to 0.75.
"the first-frame hint is empty"The Roto has no shape on the first frame of the range, or invert is ticked by mistake.
"hint sequence has N frames but the plate needs M"The hint covers a different frame range from the key. Use the same first/last.
"this shot is already being keyed"Another key of this shot is running. Wait or cancel it. If nothing is running, delete the file .running in the shot folder.
"Disk full"Free space or use "Clean up a shot...".
"camera raw can't be decoded"BRAW, R3D and ARRIRAW are not supported. Export to EXR (or ProRes) from the camera software first.
Warning in log.txt or Nuke's Script Editor: "the subject touches the crop box edge"Part of the subject may be cut off. Raise the crop margin (for example 128) or set crop to off, and key again.

15. Updating the tool later

When the tool is improved on the first laptop, there are two ways to bring the changes to the other PC:

A. With GitHub access on the other PC

The nuke plugin folder is a git copy of the private repository. If Git is installed and signed in to the GitHub account that owns the repository:

cd /d "D:\nuke plugin"
git pull

Restart Nuke afterwards.

B. Without GitHub (USB again)

  1. On the first laptop, rebuild the share folder: 
    powershell -ExecutionPolicy Bypass -File "D:\nuke plugin\tools\make_bundle.ps1" -Dest "D:\CK2_bundle"
  2. Copy it to the USB drive and run install_bundle.ps1 on the other PC again, as in section 4.

Reinstalling replaces the program files only. Your shots in the shots folder are not touched.
